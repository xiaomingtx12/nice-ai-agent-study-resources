01 平台定义与总览

先讲平台解决什么问题、核心资产是什么、用户如何从想法走到可运行应用。

02 配置资产与平台底座

应用、模型、工具、工作流、知识库这些资产怎么存、怎么装、怎么版本化。

03 Agent 运行时与记忆机制

请求进入后怎样装上下文、选模型、拼工具、跑双模式 Agent，并在主链里处理短期记忆、长期摘要、事件流和中断恢复。

04 工具与外部能力平台

Builtin / API / MCP 工具如何统一注册、调试、鉴权和执行，并被 Agent / Workflow 共用。

05 知识库与检索链路

只讲文档上传、解析、切分、索引、召回、融合，以及检索结果如何被 Tool 化复用。

06 Workflow 编排引擎

前端 DSL、draft / publish 双态、图校验、LangGraph 编译、工作流工具化闭环。

07 发布、治理与异步执行

多租户隔离、API Key、队列、预算、发布门禁、后台任务、观测性这些生产化能力。

08 场景模板与手搓路线

把前面的底座和能力重新装回客服、内容生产、企业知识助手等场景模板。

Boundary Change
并入 Agent 的内容

短期记忆：历史裁剪、token budget、上下文拼装。

长期记忆：摘要生成、异步更新、推理前注入。

运行时联动：记忆何时读、何时写、何时阻塞、何时异步。

留在知识库篇的内容

知识生产链：上传、解析、切块、向量化、索引。

知识消费链：召回、重排、融合、Tool 化。

边界强调：知识库不等于记忆，检索是外部知识接入，记忆是会话状态管理。
