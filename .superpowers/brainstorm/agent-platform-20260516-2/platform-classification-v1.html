Mainline Order
推荐主线：先底座，再运行时，再业务能力，再治理，再场景

01 平台定义与总览

平台解决什么问题，目标用户是谁，核心资产和核心业务流是什么。

02 配置资产与平台底座

应用配置、模型配置、工具配置、工作流配置、知识库配置怎么存、怎么装配、怎么版本化。

03 Agent 运行时内核

请求进入后怎样装上下文、选模型、拼工具、跑双模式 Agent、输出事件流和中断控制。

04 工具与外部能力平台

Builtin / API / MCP 工具如何统一注册、调试、鉴权和执行。

05 知识库与记忆系统

文档入库、切分、检索、融合、短期上下文、长期摘要记忆如何接到主对话链路。

06 Workflow 编排引擎

前端 DSL、草稿/发布双态、图校验、LangGraph 编译、工作流工具化复用怎么闭环。

07 发布、治理与异步执行

多租户隔离、API Key、队列、预算、发布门禁、后台任务、观测性如何补齐生产化能力。

08 场景模板与手搓路线

把前面能力重新装回客服、内容生产、企业知识助手等实际应用模板。
