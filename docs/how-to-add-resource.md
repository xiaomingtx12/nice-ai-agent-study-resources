# 如何新增一条资源

这个站点不是教程仓库，而是“资源导航 + 锐评 + 学习沉淀”的组合。

所以新增一条资源时，先别急着写长笔记，先把最关键的结构搭对。

## 推荐目录

```text
docs/resources/<resource-name>/
  index.md
  review.md
  notes/
    index.md
```

## 最小要求

1. `index.md`

写清楚这条资源是什么、适合谁、不适合谁、为什么值得收录。

2. `review.md`

单独写你的判断。别写成摘要，要回答“值不值得花时间”和“该怎么用这条资源”。

3. `notes/`

把真正学的时候留下来的东西放这里。可以是章节总结、踩坑记录、复盘，也可以只是某个问题的短笔记。

## 写的时候要克制什么

- 不要把原教程再复述一遍
- 不要写一堆正确但没判断的话
- 不要用“我收获很多”“深入理解了”这种空话糊过去

## 一个够用的判断框架

- 它解决了我什么问题
- 它最强的部分在哪里
- 它讲得最虚的地方在哪里
- 我会推荐给什么阶段的人
- 如果时间只够看一部分，应该先看哪部分
