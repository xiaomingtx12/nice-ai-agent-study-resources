# Nice AI 资源库

这不是一个“把链接堆上来就完事”的收藏夹。

这个站点只做三件事：

- 帮我筛选值得花时间的 AI 学习资源
- 直接给出判断，不绕弯子，不假装客观中立
- 把真正消化过的内容沉淀成以后还会回看的笔记

## 你能在这里看到什么

- [资源导航](./resources/index.md)：先看学习地图、资源角色和起步顺序，再决定要不要投入时间
- [方法与复盘](./notes/index.md)：放跨资源可复用的学习方法、踩坑记录和阶段性判断
- [应用沉淀](./application-notes/index.md)：放我对 AI 应用的拆解框架、设计判断和后续案例复盘
- [关于我](./about/index.md)：如果你想知道这个站点是谁在写、为什么会一直往 AI 应用和架构这条路走，可以看这里
- [共建与模板](./templates/index.md)：给想一起补资源的人一套可执行的共建流程和写作骨架

## 这个站点怎么用

如果你只是想找资源，先去看 [资源导航](./resources/index.md)。

如果你已经决定开始学某个资源，优先看它的三类内容：

- 资源总览：它讲什么、适合谁、不适合谁
- 锐评：它真正强在哪，哪些地方别抱太高预期
- 学习沉淀：我学的时候留下的笔记、总结和踩坑

如果你更关心我会怎么拆一个 AI 应用，而不是继续看资源评论，可以直接去看 [应用沉淀](./application-notes/index.md)。

如果你想知道这个站点背后的人、技术背景和现在的关注点，可以看 [关于我](./about/index.md)。

我现在刻意保留了七种不同气质的材料：

- `HelloAgents` 更像入场后的主线地图，帮我把 Agent 这件事先串起来
- `AI Agents From Zero` 更像一条项目驱动的 Agent 实战路径，适合从基础一路摸到 workflow、MCP、RAG 和项目落地
- `AI Agent Book` 更像往架构和生产落地继续推进的一本手册
- `Learn Claude Code` 更像一门 agent harness 拆解课，适合把“Claude Code 为什么好用”拆回具体机制
- `OpenClaw 源码解析` 更像一份 control plane 源码导读，适合从真实大项目里看消息网关、Agent 运行时、扩展和安全是怎么揉在一起的
- `Claude Code Architecture（CCB）` 更像一份逆向分析白皮书，适合从五层架构、工具权限、压缩、遥测与配置下发这些角度理解 Claude Code
- `Easy-Vibe` 更像一条面向产品和非科班开发者的 AI 编程学习路径，适合看“从会说需求到把应用做出来”这条路怎么被设计出来

## 收录原则

- 不追求全，只收我认为值得反复回看的东西
- 不写“万金油式总结”，每篇都必须给出明确判断
- 不搬运原文，只写自己的理解、取舍和使用方式
