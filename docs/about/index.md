# 关于我

你好，我是这个站点的维护者，也是在这里持续整理、记录和反思的人。

这个站点更像是我一边学习、一边筛选、一边沉淀出来的 AI 应用学习仓库。

我会把查到的开源教程、项目资料和自己的学习笔记放在一起，不只记录“看过什么”，也尽量留下“为什么值得看、学完之后留下了什么”。

## 当前定位

目前主要关注 AI 应用、Agent 系统和后端工程落地，也持续补系统设计、架构和产品化相关的问题。

- 技术标签：AI 应用探索 / Agent 系统 / Java 后端 / 全栈工程 / 工程化实践

## 我的学习路径

### 前端起步

#### 大一（2022年~2023年）

从前端入门编程，做一些前端页面感觉很有趣，主要看b站pink老师学前端三件套，后面学JS进阶，看的coderwhy老师课程，讲的JS高级很细节，加深了对JS的理解。

回头看，这个阶段的我更偏向概念型学习，买了不少前端相关的书，也总想着先把 CSS、JS 这些基础吃透。但项目意识还比较弱，做得更多的是部门里的响应式页面和一些设计稿还原。

#### 大二上（2023年~2024年）

开始担任部门部长，继续负责前端页面开发和新部员的技术培训。也是从这个阶段开始，我第一次更认真地去想：怎么去教部员拆页面，怎么讲清技术，怎么把自己会的东西真正传递给别人。

### 后端扩展

#### 大二下到大三（2024~2025年）

受学校课程和当时就业焦虑的影响，我开始把重心往 Java 后端扩。中间也尝试过 Node.js、three.js 这类方向，但最后还是更系统地补了 Java 后端这一套。

主要扩展了 Spring系列、JUC、JVM、微服务、分布式和中间件这些更偏系统与工程化的内容。

中间也学着做了一些 Java + Vue 全栈项目，外卖、点评、博客、社区、协同云图库，也会去看一些 Java 框架和中间件的实现。

这个阶段我开始更在意一个系统为什么要这样组织、一个框架和中间件在工程里解决了什么问题。也是在这时候，我接触过调用 AI 接口，使用 Spring AI 配合提示词做过一些简单应用。

### 全栈开发实习

#### 大三下暑假（2025年6-9月）

参与了一段全栈开发相关的实习，角色偏全栈开发，技术栈主要是 Java + Vue + Uniapp。

这段经历对我来说很重要，因为它让我第一次更具体地进入真实开发环境，开始按照需求去完成实际功能。刚开始经验不足，遇到问题会比较多，也经常需要请教部门里的前辈，但也是在这个过程中，慢慢开始理解团队协作、需求落地和工程开发到底是什么样子。

### 开始接触 AI 应用相关方向

#### 实习之后，大四上

前端、后端和全栈实习这些经历，也是在不断帮我建立工程落地的视角。也是在这个过程中，我开始持续关注 AI 应用相关的方向：它一方面和我原来熟悉的后端工程有连接，另一方面也让我更在意用户场景、产品形态，以及系统怎么真正落到可用的应用里。

一开始我是从 Spring AI 这类更贴近原来后端栈的东西切进去，后面逐渐扩到 Python 生态里的 LangChain、LangGraph，再到更具体的 Agent 应用系统。

## 我现在持续关注的几个问题

- AI 应用与 Agent 系统
- 后端相关和系统设计
- coding agent / agent harness 这类更偏产品系统的问题
- 从学者思维到构建者思维的转变

这些方向对我来说不是彼此割裂的。越往后看，越会发现它们最后都会汇到同一个问题上：怎么把能力、系统和场景真正组织起来。

## 回顾复盘我发现我这过程中缺少的能力

- 学者思维贯穿大部分时间，没有意识到自己也可以成为一个Builder构建者
- 战术上的勤奋掩盖思维上的懒惰，思考较浅，容易停留在表层

## 我最近的一个变化

最近有一种顿悟，某种程度上也是 AI 的发展在推着我重新思考很多事情。

以前我会更容易沉浸在某个技术点上，比如把一个编程语言、一个框架、一个方向学深一点，心里默认只要足够努力，最后大概率就能找到一个不错的位置。

但现在我越来越觉得，光是“学会”已经不够了。更重要的是不断提升自己的认知、思考能力和判断力：

- 能不能看清问题本身
- 能不能分辨什么值得学、什么值得做
- 能不能判断什么问题真的重要
- 能不能及时发现自己的认知是不是已经落后了

对我来说，思维不是一次性定型的东西，而是要不断更新认知、调整思考方式、修正判断标准的过程。所以这个站点后面也不会只堆资料，我会更在意把自己的判断、取舍和复盘留下来。

## 我希望自己后面做什么

持续探索 AI 应用和后端相关的问题，同时也希望慢慢从“会学、会做”走到“能做出一些真的有意思、也有实际价值的东西”。

如果这个站点后面能持续沉淀出这种东西，那它对我来说就不只是单纯的学习记录，而是一套真正对自己和别人都有用的长期积累。
