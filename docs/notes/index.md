# 方法与复盘

这里不放某一条具体资源的读书笔记，也不承担“资源导航”的功能。

这里更像是一个公共练习场，去做刻意练习，培养自己的思考方式，当你遇到一个已知的解决方案时，能够再思考深一步。

同时将思考的东西去有逻辑性的表达记录下来。在AI时代更应该锻炼人的特性，思考、创造，不应该在是学习成为AI那样记录了很多的解决方案，而没有较深的理解。

这里也更像这个站点的公共工作台，专门放那些跨资源、跨项目还能继续复用的东西：

- 学习方法
- 踩坑复盘
- 对 Agent 学习路径的阶段性判断
