# 方法与复盘

这里不放某一条具体资源的读书笔记，也不承担"资源导航"的功能。

它更像一个公共练习场：去做刻意练习，培养自己的思考方式——当你遇到一个已知解决方案时，能再往深想一步，并把思考有逻辑地记录下来。AI 时代更应该锻炼人的特性（思考、创造），而不是把自己学成"记了很多方案却没有深理解的 AI"。

同时这里也是这个站点的公共工作台，专门放那些跨资源、跨项目还能继续复用的东西：学习方法、踩坑复盘、对 Agent 学习路径的阶段性判断。
