# 方法与复盘

这一栏是闭环的回箭头：把资源导航和应用拆解里得到的东西，提炼成能带到下一次的判断、模式和检查点。不追求记全方案，追求把关键的那几条写成下次真会回头翻、真会照着校准的文章——而不是写完就忘的笔记。

这也是跨资源、跨项目还能继续复用的东西的存放地：学习方法、踩坑复盘、对 Agent 学习路径的阶段性判断。

## 这一节该看什么

- 想知道怎么学这类资源：看这里
- 想看跨项目也成立的方法和判断：看这里
- 想看阶段性的学习路径调整、判断更新和复盘：也放这里

## 这一节不放什么

- 单条资源的总览或章节笔记（这属于资源导航）
- 为了留痕而留痕的日常流水账

这些内容都应该回到 [资源导航](../resources/) 下的具体资源目录里。

## 这一栏怎么回到前两栏

- 提炼出的检查点，回到资源导航：下次读资源时知道该深挖什么、跳过什么。
- 提炼出的问题清单，回到应用拆解：下次拆项目时带着更准的问题去。
- 只有真被用上，这栏才算闭合了闭环——不然就是条直线收进抽屉。
