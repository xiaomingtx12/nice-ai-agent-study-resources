# Dify 架构拆解（v1.15.0）

这一组是基于 Dify v1.15.0 源码做的架构拆解，共 16 篇，覆盖六进程拓扑、应用配置层、Agent 运行时、推理策略、上下文记忆、异步事件、工具注册、模型供给与扩展、RAG 索引/检索、Workflow 引擎、MCP 协议、多租户与安全、可观测性、触发器到实战部署。

## 这一组怎么读

- **先建坐标系再进主题**。`dify-01`（整体架构）是综述图，但读完不一定会用。先读 `dify-01` 拿到六进程拓扑那张总图，再挑你关心的主题深入，事半功倍。
- **跨文档互链很密**。`dify-03/04/05/06` 四篇共享一个主语（Agent 运行时），顺序读；`dify-09/10` 同理（RAG 索引与检索）；`dify-11/15` 同理（Workflow 与 Trigger）。
- **配置层是隐式主线**。`dify-02`（应用配置层）字面上不起眼，但它讲的 `AppGenerateEntity`、`AppMode`、DSL 序列化是后面 03/04/11 都依赖的输入对象，不能跳。

## 版本与引用约定

- 所有文档基于 Dify v1.15.0（plugin daemon 0.6.3-local，sandbox 0.2.15）。本地部署版本不同时，源码行号可能偏移。
- 源码引用以 `(path/to/file.py:123)` 或 `file.py:123` 形式标位置，不可点击，仅用于定位代码在系统里的落点。
