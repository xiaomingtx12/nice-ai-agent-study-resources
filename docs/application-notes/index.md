# 应用拆解

## 栏目分工

| 栏目                        | 组织<br />方式                                                     | 主要回答                                                   |
| --------------------------- | ------------------------------------------------------------------ | ---------------------------------------------------------- |
| 工程化                      | 按项目组织，深入关键模块；覆盖框架、平台、完整应用与基础设施       | 一个具体工程问题怎样被解决，哪些设计值得复用？             |
| 开源项目工程对比            | 按工程问题组织，对照不同项目的架构、数据流与故障路径               | 不同实现各承担什么责任、代价和运行约束？                   |
| [产品业务](./product/index.md) | 按用户任务组织，支持单产品拆解与同场景比较，已有企业案例及开源应用 | 用户怎样完成任务，结果怎样交付，业务价值与采用成本是什么？ |
