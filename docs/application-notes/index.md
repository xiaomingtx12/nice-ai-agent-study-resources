# 应用沉淀

这一节和“资源导航”“方法与复盘”都不一样。

这里不是在点评别人的资料，也不是在写通用方法论，而是专门放我自己在学习、理解和尝试 AI 应用过程中，愿意拿出来分享的文档沉淀。

## 这里会放什么

- 我对某类 AI 应用的功能拆解
- 某个 Agent 应用方向的设计判断
- 做项目或做 demo 之后留下来的结构化复盘
- 一些我觉得值得单独展开讲的应用侧问题

## 这里不放什么

- 单条资源的收录说明
- 纯粹的学习流水账
- 只是换个说法复述概念的笔记

## 当前内容

- [我想在这里沉淀什么样的 AI 应用文档](./what-i-want-to-write-here.md)

## 我为什么单独开这一栏

我越来越觉得，只会“看资源”是不够的。

真正能把人往前推的，往往是自己开始把问题拆成产品、系统和实现三个层面之后留下来的东西。这个栏目就是给这些内容留位置的。
