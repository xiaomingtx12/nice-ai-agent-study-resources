# HelloAgents

- 官网：[https://datawhalechina.github.io/hello-agents/](https://datawhalechina.github.io/hello-agents/)
- 项目仓库：[https://github.com/datawhalechina/hello-agents](https://github.com/datawhalechina/hello-agents)
- 我当前的定位：把它当作一套 Agent 学习地图，而不是唯一标准答案

## 这条资源在讲什么

它想解决的不是“怎么写一个 prompt”，而是更靠近另一层问题：如果你想把 Agent 做成一个能持续工作的系统，工具、记忆、上下文、评估这些东西该怎么连起来看。

对我来说，这正是它最值得看的地方。很多资料会教你拼 demo，但不太愿意继续往下讲“系统为什么这样搭”。HelloAgents 至少在努力补这个空档。

## 适合谁

- 已经会基本的 Python 和 API 调用，不想一直停留在 demo 阶段的人
- 想给自己补一张 Agent 知识地图的人
- 手头已经在看多个框架，想先找一条中文主线把概念串起来的人

## 不太适合谁

- 还没跑通过任何 LLM API、现在只想零门槛入门的人
- 指望只靠一套教程就把 Agent 工程问题一次性学透的人

## 我为什么把它收进来

- 中文资料里，愿意同时碰“应用上手”和“设计原理”的并不多
- 它比较适合拿来搭框架感，不容易一上来就陷进单一工具或单一框架的细节里
- 即使后面不完全照着它学，它也能帮我判断自己下一步该补哪块短板

## 建议怎么用

别把它当教材从头背到尾，更别把每一章都当成“必须精读”的圣经。

我更推荐这样用：

1. 先通读目录和前言，弄清这套教程到底想把你带到哪里。
2. 遇到自己当前最缺的模块，就先啃那一块，比如工具调用、记忆、上下文工程。
3. 每看完一段，强迫自己留下一个能复用的东西，比如一段最小示例、一份 checklist，或者一条清晰判断。
