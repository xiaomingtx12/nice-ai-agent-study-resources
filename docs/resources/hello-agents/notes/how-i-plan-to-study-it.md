# 怎么学这套教程更划算

- 来源：[https://datawhalechina.github.io/hello-agents/](https://datawhalechina.github.io/hello-agents/)

## 我的目标不是“看完”

这类教程最容易出现一种假进步：目录刷完了，笔记写了一堆，但真要自己搭东西时还是不知道从哪下手。

所以我给自己定的目标不是“按顺序学完”，而是每学一段，就留下至少一个以后能复用的东西。

## 我准备留哪几种东西

- 一条明确判断：这一部分最值钱的点是什么
- 一个最小示例：哪怕只是伪代码，也得能说清怎么落
- 一份 checklist：它在真实项目里会检查哪些问题

## 我打算怎么分配精力

对我来说，所有内容并不需要平均用力。

如果某一段只是帮我建立名词感，我会快读。

如果某一段正好对应我现在的短板，比如记忆、上下文组织或者 Agent 的运行方式，我会多停一会儿，顺手补外部资料。

## 我会刻意防的坑

- 只记结论，不记适用边界
- 看到概念就觉得自己已经掌握
- 把教程笔记写得很漂亮，但没有任何实验和判断

## 我给自己的最低要求

每次学习结束之前，至少回答这三个问题：

- 这一段到底解决了什么问题
- 我现在能不能用自己的话复述出来
- 它在真实项目里会落到哪个模块

如果三个问题里有两个答不上来，那我就默认自己还没学会。
