# 先别急着通读：我为什么先把它当地图

- 来源：[https://datawhalechina.github.io/hello-agents/](https://datawhalechina.github.io/hello-agents/)

## 先说我的判断

我现在不打算把 HelloAgents 当成一本需要逐字精读的教材。

更现实的用法是：先拿它搭一张地图，知道 Agent 这件事大概有哪些关键模块、它们之间怎么连，然后再按自己当前最缺的部分往下深挖。

## 为什么我会这么看

最近这类资料很多，但有两个常见问题。

一种是太浅，只够你把 demo 跑起来，跑完还是不知道系统怎么搭。

另一种是太散，今天看这个框架，明天看那个产品，最后记了一堆名词，脑子里却没有主线。

HelloAgents 对我有用，不是因为它能一步到位解决所有问题，而是因为它看起来愿意把这些点往一条主线上串。

## 我真正想从它身上拿走什么

- 一张够清楚的 Agent 知识地图
- 一套比较像工程问题的拆法，而不是只停留在“会调模型”
- 一些可以转成自己项目 checklist 的判断框架

## 我不打算怎么学

- 不追求每章都等量投入
- 不把它写过的话原封不动搬到我的笔记里
- 不因为它讲到了某个概念，就误以为自己已经会用了

## 接下来怎么做

我会先把前言、目录和学习方法相关内容过一遍，把路径摸清。

等路线感有了，再决定先啃工具调用、记忆，还是上下文工程这一类更贴近当前需求的部分。
