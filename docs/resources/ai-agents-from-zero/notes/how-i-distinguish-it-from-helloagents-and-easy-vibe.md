# 怎么把它和 HelloAgents、Easy-Vibe 区分开看

- 来源：[https://didilili.github.io/ai-agents-from-zero/#/](https://didilili.github.io/ai-agents-from-zero/#/)
- 参考仓库：[https://github.com/didilili/ai-agents-from-zero](https://github.com/didilili/ai-agents-from-zero)

## 它和前两条路径型资源不完全一样

表面上看，`HelloAgents`、`Easy-Vibe`、`AI Agents From Zero` 都能被叫做“学习路径”。

但我现在会把它们明确拆开，因为它们各自回答的问题并不一样。

## HelloAgents 更像地图

`HelloAgents` 最像一张 Agent 主线地图。它的价值是帮人先把工具、记忆、上下文、评估这些模块串起来，先建立整体感。

## Easy-Vibe 更像 AI 编程入口设计

`Easy-Vibe` 更关心的是，怎么把人带进 AI 编程这条路，尤其是怎么让非传统开发者也能一路走到做产品、上线和持续迭代。

## AI Agents From Zero 更像“边做项目边学 Agent”

这条资源的重心比 `HelloAgents` 更实操，也比 `Easy-Vibe` 更聚焦 Agent 本身。

我会把它理解成这样一条路：不是先只建立地图，也不是先只讲产品表达，而是直接把你往 Agent 项目、框架和案例里推，让你在做的过程中补认知。

## 所以我会怎么搭配着看

如果我要先建立全局图，优先看 `HelloAgents`。

如果我要研究 AI 编程的入门路径设计，优先看 `Easy-Vibe`。

如果我要开始真正做 Agent 项目，同时又不想一路靠零散教程拼起来，`AI Agents From Zero` 会更合适。

这三条资源放在一起，正好对应三种不同问题：

- 怎么先看清全局
- 怎么把人带进来
- 怎么边做项目边把 Agent 路径走通
