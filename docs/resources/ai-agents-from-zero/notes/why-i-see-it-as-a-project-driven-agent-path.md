# 为什么我把它看成项目驱动的 Agent 实战路径

- 来源：[https://didilili.github.io/ai-agents-from-zero/#/](https://didilili.github.io/ai-agents-from-zero/#/)
- 参考仓库：[https://github.com/didilili/ai-agents-from-zero](https://github.com/didilili/ai-agents-from-zero)

## 我的第一判断

这条资源对我最大的价值，不是再讲一遍 Agent 概念，而是给出一条比较明确的“从知道一点，到真的做出项目”的推进路线。

这让它和站里偏地图、偏架构拆解的材料不太一样。

## 为什么我会这么看

它的目录组织方式已经很说明问题：不是单纯按概念分类，而是按基础、提高、项目、加餐和知识库一路往后推。

这背后的默认前提很清楚：

- 你不该只停在知道名词
- 你要真的碰项目、碰工具、碰具体框架
- 你要在动手过程中，把 Agent 这件事慢慢理解成一套能落地的系统

这就是典型的项目驱动路径，不是纯阅读型材料。

## 这对我有什么价值

我会从它身上重点拿走两类东西。

第一类，是学习顺序感。它能帮助我判断一个从零起步的人，先做什么，后做什么，哪些主题应该在项目里理解，而不是先在脑子里空转。

第二类，是迁移练习。因为它覆盖的平台和框架不少，所以我正好可以借它训练自己分辨：哪些是通用 Agent 模式，哪些只是某个生态下的操作习惯。

## 一个边界提醒

项目驱动很容易让人获得进展感，但进展感不等于理解已经扎实。

所以我会把它当作“推动我真正上手”的资源，而不是“跟完就算彻底掌握”的保证。
