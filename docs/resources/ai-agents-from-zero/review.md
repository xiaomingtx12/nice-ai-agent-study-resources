# AI Agents From Zero 锐评

先说结论：值得收，尤其适合想边做边学的人，但别把“项目很多”误解成“所有关键问题都已经学透”。

## 我觉得它最值钱的地方

第一，它是明显的项目驱动路径。很多 Agent 材料会先把概念讲一圈，但读者最后还是不知道怎么落到真实任务上。这条资源更像是在说：别只停在理解名词，跟着做，把系统和项目一点点搭出来。

第二，它把多个常见生态放在了一起。Coze、Dify、LangChain、LangGraph、MCP、RAG 这些词很多人都会接触，但常见的问题是东一榔头西一棒子。这条资源的价值之一，就是把它们放回同一条学习路径里。

第三，它的对象感比较清楚。它不是写给已经在研究 runtime、安全治理、权限模型的人，而是写给想真正开始做 Agent、同时又不想只停在最小 demo 的人。

## 我保留意见的地方

第一，覆盖面很广，而广度本身就是取舍。它能帮你迅速建立行动路径，但不代表每个主题都会讲到足够深。

第二，项目驱动内容最容易制造一种错觉：我跟着做完了，就等于我已经掌握了。实际上，做通一次和真正能独立抽象、迁移、排错，是两回事。

第三，它碰到的平台和框架比较多，这很实用，但也意味着你要警惕“工具习惯”冒充“通用方法”。如果不主动抽象，你最后记住的可能只是某个工具的使用流程。

## 值不值得投入时间

如果你现在缺的是“我到底该从哪开始做，做到什么程度才不算只会 demo”，它值得。

如果你现在更想补的是 Agent 系统设计、源码结构、权限边界、运行时治理，那它不是最高优先级。

## 如果时间有限，先从哪部分入手

- 先看整体目录，确认基础篇、提高篇、项目篇分别在解决什么问题
- 再挑一个最完整的项目主线去跑，不要一开始就平均摊开
- 做的过程中优先盯 workflow、MCP、RAG 这类迁移性更强的主题
