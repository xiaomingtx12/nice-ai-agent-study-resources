# AI Agents From Zero

- 官网：[https://didilili.github.io/ai-agents-from-zero/#/](https://didilili.github.io/ai-agents-from-zero/#/)
- 项目仓库：[https://github.com/didilili/ai-agents-from-zero](https://github.com/didilili/ai-agents-from-zero)
- 我当前的定位：把它当作一条从零入门到项目落地的 Agent 实战路径，而不是纯概念导览

## 这条资源在讲什么

这条资源最明显的特点，不是先给你一堆抽象定义，而是直接按“基础篇 -> 提高篇 -> 项目篇 -> 加餐 -> 知识库”的路线往前推。

从站点目录和仓库说明看，它想覆盖的不只是“Agent 是什么”，还包括：

- workflow、multi-agent、MCP、RAG 这些常见主题
- Coze、Dify、LangChain、LangGraph 这些经常会碰到的工具和框架
- 从基础体验一直过渡到项目级实践，甚至碰到一些偏企业级的实现

所以我会把它看成一条“边做边补认知”的学习路径。它不是那种只负责帮你建立地图的材料，而是明显更想把你推进到“真的做出东西”这一步。

## 适合谁

- 想从零开始学 Agent，但不满足于只看概念介绍的人
- 希望把 workflow、MCP、RAG、多 Agent 和项目实战串成一条路径的人
- 更习惯通过项目和案例建立理解，而不是先啃纯理论的人

## 不太适合谁

- 现在只想先要一张高层地图、不准备跟着动手的人
- 只想查某个单点框架 API，用完就走的人
- 想靠一条资源直接替代更深的架构、源码和系统治理材料的人

## 我为什么把它收进来

- 中文世界里，愿意把 Agent 学习路径一路拉到项目实战的材料并不多
- 它把多个常见生态放在同一条主线里，更适合新手先建立“这些东西各自在哪一层”的感觉
- 它和站里偏地图、偏架构、偏源码的资源形成互补，不会全都挤在同一种视角上

## 建议怎么用

我不会把它当成“从第一页到最后一页平均精读”的教材。

我更推荐这样用：

1. 先扫一遍基础篇、提高篇和项目篇目录，确认它准备把你带到哪里。
2. 如果你已经决定动手，优先围绕项目篇回看前面的知识点，不必每个专题都平均用力。
3. 每做完一个专题，强迫自己分清两件事：哪些是可迁移的 Agent 模式，哪些只是某个平台或框架的具体操作。
