# Easy-Vibe

- 官网：[https://datawhalechina.github.io/easy-vibe/zh-cn/](https://datawhalechina.github.io/easy-vibe/zh-cn/)
- 项目仓库：[https://github.com/datawhalechina/easy-vibe](https://github.com/datawhalechina/easy-vibe)
- 我当前的定位：把它当作一条面向 AI 编程与 vibe coding 的产品学习路径，而不是纯技术文档

## 这条资源在讲什么

Easy-Vibe 的出发点和站里前面几条资源很不一样。它不是先问“Agent 是什么”“Claude Code 内部怎么做”，而是直接问一个更面向结果的问题：如果一个人会描述需求，怎么借助 AI 把产品一步步做出来。

官网首页把这条路径拆成了三段：

- `Stage 1` 零基础入门：学习地图、游戏化入门、产品原型实战
- `Stage 2` 初中级开发：设计稿转代码、真实数据项目、部署上线、知识库集成
- `Stage 3` 高级开发：跨平台桌面应用、Agent 团队、长效稳定执行、个人品牌输出

仓库 README 也把它说得很直白：`In the AI era, programming starts by describing what you want.` 这意味着它关心的核心不是某个底层框架，而是“会说需求 -> 会做产品 -> 能上线 -> 能持续迭代”这条实际路径。

## 适合谁

- 对 AI 编程感兴趣，但不想先被底层概念压住的人
- 希望从产品原型、全栈落地、部署上线一路打通的人
- 想看一条更偏结果导向、更偏实战路径设计的课程的人

## 不太适合谁

- 现在最想补的是 Agent 系统底层原理、运行时或架构治理的人
- 对 vibe coding 这个方向本身持明显保留，想直接看更传统的软件工程路径的人
- 想通过一条资源把后端深水区、系统设计和工程治理一次性学透的人

## 我为什么把它收进来

- 它的视角明显不同，更偏“怎么把 AI 编程变成一条能走通的学习路径”
- 它不只讲提示词或原型，而是一路延伸到数据、部署、知识库、桌面应用、Agent 团队
- 它对“非传统开发者如何进入 AI 应用”这个问题给了一套相当具体的课程组织方式

## 建议怎么用

我不会把它当成 Agent 理论教材，也不会拿它替代更硬核的架构或源码资料。

我更推荐这样用：

1. 如果你关心的是 AI 编程学习路径，先看首页和学习地图，弄清它怎么分阶段。
2. 如果你想快速感受“会描述需求就能做出东西”这件事，先看 Stage 1。
3. 如果你已经能做原型，更值得看 Stage 2 里真实数据、部署上线、知识库这几块。
4. Stage 3 更适合当“下一阶段的能力地图”，不必一开始全啃。
