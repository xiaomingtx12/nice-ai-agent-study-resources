# 01｜HelloAgents 的“如何学习”：我的理解与执行清单（第一人称）

- 原教程：[https://datawhalechina.github.io/hello-agents/](https://datawhalechina.github.io/hello-agents/)
- 记录日期：2026-05-12

## TL;DR

我把官方的“如何学习”读成一句话：**这是一套理论+实战并重的体系，最好边学边跑代码，并且按 5 个阶段逐步加深。**
对我来说，关键不在“看完”，而在“每一章都产出一个可以复用到项目的东西”。

## 我从原文里抓到的 3 个关键信号

1) 这是“面向构建者”的教程
- 它假设我有 Python 基础、也知道怎么用 API 调 LLM
- 重点是做应用与系统，而不是训练算法推导

2) 内容是分层递进的
- 前 1–3 章是地基：概念、历史、LLM 基础
- 4–7 章开始动手：经典范式、低代码、主流框架、自研框架
- 8–12 章开始系统化：记忆/检索、上下文工程、协议、训练与评估
- 13–15 章做整合项目
- 16 章做毕业设计

3) 强烈建议配合代码实践
- 教程提供了配套代码（原文提到 code 文件夹）
- 它希望我“亲手运行、调试甚至修改”，并鼓励在 issue 区提问

## 我自己的执行清单（每次学习都过一遍）

- 我今天学的章节是：________
- 我能用 1 分钟讲清楚本章主题吗？（不行就先别往下）
- 我能写出最小例子/伪代码吗？
- 我能指出 2 个常见坑吗？
- 我能把它映射到真实工程模块吗？（Prompt / Tools / Memory / Eval / Observability / Security）
- 我下一步要做的练习是什么？（必须可执行）

## 我的“输出格式”约定

我会把产出分成两类：

- summaries：结构化总结（对外也能读懂）
- notes：碎片化记录（先不追求完整）

我会尽量让 summaries 具备“复用价值”：
- 一页能看懂
- 有 checklist
- 有最小例子
