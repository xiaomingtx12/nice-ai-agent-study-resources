# 00｜HelloAgents 总览与我的学习路线（第一人称）

- 原教程：<https://datawhalechina.github.io/hello-agents/#/>
- 项目仓库：<https://github.com/datawhalechina/Hello-Agents>
- 记录日期：2026-05-12

## TL;DR

我把 HelloAgents 当作一套“从概念到工程落地”的智能体（Agent）系统教程来学。
我的目标不是背概念，而是把每一章都转化为：**可解释的架构图 + 可跑的最小代码 + 可复用的工程 checklist**。

## 我为什么选 HelloAgents

我从首页的介绍里读到一个很明确的定位：它更偏向 **AI Native Agent** 的构建逻辑，而不是单纯“流程编排 + LLM 当后端”的应用拼装。
这正好符合我当前想提升的能力：
- 不是只会调用模型，而是能把模型能力组织成一个稳定可迭代的系统
- 能把 Agent 的关键模块拆开讲清楚（规划/工具/记忆/上下文/评估/协作）

## 我从目录结构里提炼出的主线

HelloAgents 把内容分成 5 部分（我用“学习产出”的方式重新理解它）：

1) 基础（第 1–3 章）：
- 我需要能用自己的话解释“什么是 Agent、为什么需要 Agent、LLM 在这里扮演什么角色”

2) 构建（第 4–7 章）：
- 我需要能亲手实现至少一个经典范式（例如 ReAct）
- 我需要能在低代码平台与代码框架之间建立“可迁移”的认知（不是换个平台就重学）

3) 高级（第 8–12 章）：
- 我需要把 Agent 做成“可长期运行的系统”：记忆/检索、上下文工程、协议、训练与评估

4) 综合案例（第 13–15 章）：
- 我需要把模块组合到真实项目里：从需求→架构→迭代→复盘

5) 毕设（第 16 章）：
- 我把它当作一次“端到端项目交付演练”：选题、里程碑、评估指标、最终 demo

## 我的学习方式（我自己的执行版）

我会坚持 3 个输出物：

- **章节总结（summaries）**：每章 1 篇，必须包含：
  - 我学到了什么（3–7 条）
  - 我能复述的最小定义/公式
  - 我能跑起来的最小例子（哪怕是伪代码）
  - 我踩过的坑 / 我会犯的错
  - 下一步练习（可执行）

- **随手记录（notes）**：我先把碎片写下来，再提炼到总结

- **工程 checklist（附在总结末尾）**：
  - 这章的内容对应到实际项目里，要检查哪些点？（比如：工具选择、错误处理、观测指标、prompt 结构）

## 我打算怎么推进（时间盒）

- 第 0 周：读完“前言 + 如何学习”，把环境跑通
- 第 1 周：完成第 1–3 章总结（每章 1 篇）
- 第 2–3 周：完成第 4–7 章（至少复现 1 个范式 + 跑 1 个框架 demo）
- 第 4 周：从第 8–12 章挑 2 个我最缺的点深挖（优先：上下文工程 / 评估）
